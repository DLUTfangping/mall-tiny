# 药材保障模块开发记录

## 开发概述

药材保障模块用于医院药材管理，包含药材字典、用法用量、库存预警等功能。

## 开发时间线

- **2026-04-27**：初始化模块，添加药材保障+药材字典菜单
- **2026-04-29**：扩展药材字典表结构，添加用法用量、库存预警功能
- **2026-05-08**：新增药品分类字段（NORMAL/ANESTHETIC/PSYCHOTROPIC_I/PSYCHOTROPIC_II）
- **2026-05-09**：新增基本规格字段（base_spec）、是否需要皮试字段（skin_test_required）；包装规格改为自动拼接

## 功能 2：药品字典数据库设计

### 2.1 数据库表设计

**表名**：`medicine_drug`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | bigint(20) | 主键，自增 |
| `drug_code` | varchar(64) | 药品编码（唯一） |
| `drug_name` | varchar(100) | 药品名称 |
| `common_name` | varchar(100) | 通用名 |
| `english_name` | varchar(100) | 英文名 |
| `drug_type` | varchar(20) | 药品类型 |
| `spec` | varchar(100) | 包装规格（由基本规格×转换率+基本单位/包装单位自动拼接生成） |
| `unit` | varchar(20) | 包装单位（盒、瓶、片、克） |
| `manufacturer` | varchar(200) | 生产厂家 |
| `approval_number` | varchar(64) | 批准文号 |
| `barcode` | varchar(64) | 条形码 |
| `storage_condition` | varchar(100) | 储存条件 |
| `min_stock` | decimal(10,2) | 最低库存量 |
| `max_stock` | decimal(10,2) | 最高库存量 |
| `default_supplier` | varchar(200) | 默认供应商 |
| `insurance_code` | varchar(64) | 医保编码 |
| `is_essential` | int(1) | 基本药物标识 |
| `drug_category` | varchar(30) | 药品分类 |
| `base_spec` | varchar(30) | 基本规格（如0.75mg/片） |
| `prescription_type` | varchar(20) | 处方药分类 |
| `skin_test_required` | int(1) | 是否需要皮试：0=否，1=是 |
| `dosage_form` | varchar(30) | 剂型 |
| `base_unit` | varchar(20) | 基本单位（片、粒、支、克、毫升） |
| `conversion_rate` | decimal(10,4) | 转换率（包装单位与基本单位的转换关系） |
| `status` | int(1) | 状态 |
| `remark` | varchar(500) | 备注 |
| `create_time` | datetime | 创建时间 |
| `update_time` | datetime | 更新时间 |

**枚举值说明**：
- `drug_type`：WESTERN=西药, TCM=中成药, HERB=中药饮片
- `prescription_type`：OTC_RX=处方药, OTC_OTC=非处方药, OTC_BOTH=双跨
- `is_essential`：1=是国家基本药物，0=否
- `dosage_form`：TABLET=片剂, CAPSULE=胶囊, INJECTION=注射剂, GRANULE=颗粒, SOLUTION=溶液, OINTMENT=软膏, PATCH=贴剂, HERB=饮片
- `drug_category`：NORMAL=普通药品, ANESTHETIC=麻醉药品, PSYCHOTROPIC_I=精神类I类, PSYCHOTROPIC_II=精神类II类

## 功能 3：药品用法表设计

### 3.1 数据库表设计

**表名**：`medicine_drug_usage`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | bigint(20) | 主键，自增 |
| `drug_code` | varchar(64) | 药品编码（关联 medicine_drug） |
| `usage` | varchar(30) | 用法 |
| `frequency` | varchar(30) | 频次 |
| `single_dose` | decimal(10,4) | 单次剂量 |
| `dose_unit` | varchar(20) | 剂量单位 |
| `max_daily_dose` | decimal(10,4) | 日最大剂量 |
| `age_range` | varchar(50) | 适用年龄范围 |
| `contraindication` | varchar(500) | 禁忌症 |
| `remark` | varchar(200) | 备注 |
| `status` | int(1) | 状态：0=禁用，1=启用 |
| `create_time` | datetime | 创建时间 |
| `update_time` | datetime | 更新时间 |

**索引**：idx_drug_code

**枚举值说明**：
- `usage`：ORAL=口服, INJECTION=注射, IV_DRIP=静滴, EXTERNAL=外用, INHALATION=吸入, RECTAL=直肠给药
- `frequency`：QD=每日1次, BID=每日2次, TID=每日3次, QID=每日4次, Q12H=每12小时, Q8H=每8小时, PRN=必要时

| `modules/medicine/service/impl/MedicineDrugUsageServiceImpl.java` | Service 实现 |
| `modules/medicine/controller/MedicineDrugUsageController.java` | Controller |

### 3.3 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/drugUsage/list/{drugCode}` | GET | 根据药品编码获取用法列表 |
| `/drugUsage/create` | POST | 创建药品用法 |
| `/drugUsage/update/{id}` | POST | 更新药品用法 |
| `/drugUsage/delete/{id}` | POST | 删除药品用法 |

- 列表展示药品信息

- 展示所有药品的预警配置
- 支持按药材类型、关键词搜索
- 配置弹窗设置预警参数

## 数据库 SQL 汇总

```sql
-- 1. 添加新字段到 medicine_drug 表
ALTER TABLE medicine_drug
ADD COLUMN `dosage_form` varchar(30) DEFAULT NULL COMMENT '剂型' AFTER `prescription_type`,
ADD COLUMN `base_unit` varchar(20) DEFAULT NULL COMMENT '基本单位' AFTER `dosage_form`,
ADD COLUMN `conversion_rate` decimal(10,4) DEFAULT NULL COMMENT '转换率' AFTER `base_unit`,
ADD COLUMN `drug_category` varchar(30) DEFAULT NULL COMMENT '药品分类：NORMAL=普通药品, ANESTHETIC=麻醉药品, PSYCHOTROPIC_I=精神类I类, PSYCHOTROPIC_II=精神类II类' AFTER `is_essential`,
ADD COLUMN `base_spec` varchar(30) DEFAULT NULL COMMENT '基本规格（如0.75mg/片）' AFTER `drug_category`,
ADD COLUMN `skin_test_required` int(1) DEFAULT 0 COMMENT '是否需要皮试：0=否，1=是' AFTER `prescription_type`;

-- 2. 创建 medicine_drug_usage 用法表
CREATE TABLE `medicine_drug_usage` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `drug_code` varchar(64) NOT NULL,
  `usage` varchar(30) DEFAULT NULL COMMENT '用法',
  `frequency` varchar(30) DEFAULT NULL COMMENT '频次',
  `single_dose` decimal(10,4) DEFAULT NULL COMMENT '单次剂量',
  `dose_unit` varchar(20) DEFAULT NULL COMMENT '剂量单位',
  `max_daily_dose` decimal(10,4) DEFAULT NULL COMMENT '日最大剂量',
  `age_range` varchar(50) DEFAULT NULL COMMENT '适用年龄范围',
  `contraindication` varchar(500) DEFAULT NULL COMMENT '禁忌症',
  `remark` varchar(200) DEFAULT NULL COMMENT '备注',
  `status` int(1) DEFAULT '1' COMMENT '状态：0=禁用，1=启用',
  `create_time` datetime DEFAULT NULL,
  `update_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_drug_code` (`drug_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8;

-- 3. 创建 medicine_drug_warning 预警表
CREATE TABLE `medicine_drug_warning` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `drug_code` varchar(64) NOT NULL,
  `min_warning_stock` decimal(10,2) DEFAULT NULL COMMENT '最低预警库存量',
  `max_warning_stock` decimal(10,2) DEFAULT NULL COMMENT '最高预警库存量',
  `validity_warning_days` int DEFAULT NULL COMMENT '有效期预警天数',
  `batch_warning_enabled` int(1) DEFAULT '0' COMMENT '是否启用批号预警',
  `reorder_point` decimal(10,2) DEFAULT NULL COMMENT '再订货点',
  `inspection_cycle` int DEFAULT NULL COMMENT '盘点周期（天）',
  `remark` varchar(200) DEFAULT NULL COMMENT '备注',
  `create_time` datetime DEFAULT NULL,
  `update_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_drug_code` (`drug_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8;

-- 4. 添加库存预警菜单
INSERT INTO ums_menu (parent_id, create_time, title, level, sort, name, icon, hidden)
VALUES (40, NOW(), '库存预警', 1, 1, 'drugWarning', 'product-list', 0);
```
