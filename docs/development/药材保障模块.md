# 药材保障模块开发记录

## 开发概述

以添加"药材保障"一级菜单和"药材字典"二级菜单为示例，演示如何在 mall-tiny 项目中添加新菜单。

## 开发时间

2026-04-27

---

## 功能 1：添加菜单示例（药材保障 + 药材字典）

### 1.1 后端改动

**文件**：`sql/mall_tiny.sql`

```sql
-- 一级菜单：药材保障（id 自增）
INSERT INTO ums_menu (parent_id, create_time, title, level, sort, name, icon, hidden)
VALUES (0, NOW(), '药材保障', 0, 0, 'medicine', 'product', 0);

-- 二级菜单：药材字典
INSERT INTO ums_menu (parent_id, create_time, title, level, sort, name, icon, hidden)
VALUES (LAST_INSERT_ID(), NOW(), '药材字典', 1, 0, 'medicineDrug', 'product-list', 0);
```

**注意**：`name` 字段不能与数据库中已有菜单重复（如 `pms` 是商品模块，已被占用）

### 1.2 前端改动

#### 文件 1：`src/router/index.js`

添加路由配置：

```javascript
{
  path: '/medicine',
  component: Layout,
  redirect: '/medicine/drug',
  name: 'medicine',
  meta: {title: '药材保障', icon: 'product'},
  children: [{
    path: 'drug',
    name: 'medicineDrug',
    component: () => import('@/views/medicine/drug/index'),
    meta: {title: '药材字典', icon: 'product-list'}
  }]
}
```

#### 文件 2：`src/views/medicine/drug/index.vue`

创建页面组件（空白模板，待开发具体功能）

---

## 关键对应关系

```
后端 ums_menu.name = 'medicine'     ←→  前端 route.name = 'medicine'
后端 ums_menu.name = 'medicineDrug' ←→  前端 route.name = 'medicineDrug'
```

**注意**：前后端的 `name` 字段必须完全一致，菜单才能正确显示和访问。

## 功能 2：药品字典数据库设计

### 2.1 数据库表设计

**表名**：`medicine_drug`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | bigint(20) | 主键，自增 |
| `drug_code` | varchar(64) | 药品编码（唯一） |
| `drug_name` | varchar(100) | 药品名称 |
| `common_name` | varchar(100) | 通用名 |
| `english_name` | varchar(100) | 英文名 |
| `drug_type` | varchar(20) | 药品类型 |
| `spec` | varchar(100) | 规格 |
| `unit` | varchar(20) | 单位 |
| `manufacturer` | varchar(200) | 生产厂家 |
| `approval_number` | varchar(64) | 批准文号 |
| `barcode` | varchar(64) | 条形码 |
| `storage_condition` | varchar(100) | 储存条件 |
| `min_stock` | decimal(10,2) | 最低库存量 |
| `max_stock` | decimal(10,2) | 最高库存量 |
| `default_supplier` | varchar(200) | 默认供应商 |
| `insurance_code` | varchar(64) | 医保编码 |
| `is_essential` | int(1) | 基本药物标识 |
| `prescription_type` | varchar(20) | 处方药分类 |
| `status` | int(1) | 状态 |
| `remark` | varchar(500) | 备注 |
| `create_time` | datetime | 创建时间 |
| `update_time` | datetime | 更新时间 |

**枚举值说明**：
- `drug_type`：WESTERN=西药, TCM=中成药, HERB=中药饮片
- `prescription_type`：OTC_RX=处方药, OTC_OTC=非处方药, OTC_BOTH=双跨
- `is_essential`：1=是国家基本药物，0=否

### 2.2 后端实现文件

| 文件 | 说明 |
|------|------|
| `sql/mall_tiny.sql` | 建表语句（已追加） |
| `modules/medicine/model/MedicineDrug.java` | 实体类 |
| `modules/medicine/mapper/MedicineDrugMapper.java` | Mapper |
| `modules/medicine/service/MedicineDrugService.java` | Service 接口 |
| `modules/medicine/service/impl/MedicineDrugServiceImpl.java` | Service 实现 |
| `modules/medicine/controller/MedicineDrugController.java` | Controller |

### 2.3 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/drug/list` | GET | 分页查询药品字典 |
| `/drug/{id}` | GET | 获取药品详情 |
| `/drug/create` | POST | 创建药品 |
| `/drug/update/{id}` | POST | 更新药品 |
| `/drug/delete/{id}` | POST | 删除药品 |
| `/drug/updateStatus/{id}` | POST | 修改药品状态 |
