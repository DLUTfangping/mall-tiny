# 药材保障模块开发记录

## 开发概述

药材保障模块用于医院药材管理，包含药材字典、用法用量、库存预警、药房管理等功能。

## 开发时间线

- **2026-04-27**：初始化模块，添加药材保障+药材字典菜单
- **2026-04-29**：扩展药材字典表结构，添加用法用量、库存预警功能
- **2026-05-08**：新增药品分类字段（NORMAL/ANESTHETIC/PSYCHOTROPIC_I/PSYCHOTROPIC_II）
- **2026-05-09**：新增基本规格字段（base_spec）、是否需要皮试字段（skin_test_required）；包装规格改为自动拼接；新增药房管理功能
- **2026-05-10**：新增药材入库功能（含入库单管理、确认入库）；新增药材库存功能（支持按药房/药品名称/批号/药品分类/药材类型筛选，库存不足预警警示）
- **2026-05-12**：新增药材出库功能（含出库单管理、出库确认）；入库/出库明细表增加包装单位字段
- **2026-05-13**：库存列表显示当前库存+基本单位，单价显示为"X元/盒"格式；预警设置增加批号预警阈值字段
- **2026-05-27**：库存新增双视图模式（批次视图/药品总库存）；总库存按药品合并显示，预警判断基于预警设置表的最低/最高库存阈值；后端 MedicineStock 模型增加 `maxWarningStock` 字段；字典维护模块上线（字典类型+字典明细双表设计，支持状态开关）；出库单位显示具体名称（盒/片），删除出库明细库存数量列

ALTER TABLE medicine_drug

ADD COLUMN `base_unit` varchar(20) DEFAULT NULL COMMENT '基本单位' AFTER `dosage_form`,

## 功能 10：库存预警详解

### 10.1 预警字段说明

| 字段 | 说明 | 计算公式/用法 |
|------|------|-------------|
| `min_warning_stock` | 最低预警库存量 | 当总库存≤此值时触发最低预警 |
| `max_warning_stock` | 最高预警库存量 | 当总库存≥此值时触发最高预警（库存积压） |
| `validity_warning_days` | 有效期预警天数 | 药品到期前N天触发预警，提示优先使用 |
| `batch_warning_enabled` | 是否启用批号预警 | 0=否，1=是 |
| `batch_warning_threshold` | 批号预警阈值 | 当某批号库存≤此值时触发批号预警 |
| `reorder_point` | 再订货点 | 当总库存≤此值时提示需要重新采购 |
| `inspection_cycle` | 盘点周期（天） | 每N天需要做一次库存盘点 |

### 10.2 预警类型说明

1. **最低/最高预警库存**：针对该药品**所有批号总库存**的总量控制
2. **批号预警阈值**：针对**单个批次**的库存控制，避免某批次断货
3. **有效期预警**：针对即将到期药品，提示优先使用避免过期
4. **再订货点**：触发采购提醒的阈值
