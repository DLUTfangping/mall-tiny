# 新手入门：如何在 mall-tiny 添加菜单

## 目标

以添加**药材保障**一级菜单和**药材字典**二级菜单为例，说明前后端需要做的改动。

---

## 一、整体架构理解

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  前端 Vue   │ ←── │  后端 API   │ ←── │   数据库    │
│  路由+视图  │     │  Controller │     │  ums_menu  │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 菜单数据流

1. **数据库** `ums_menu` 表存储菜单数据（id, parent_id, title, name, icon 等）
2. **后端** 查询菜单，返回给前端（通过 `/admin/info` 接口）
3. **前端** 根据返回的菜单过滤路由，侧边栏渲染菜单

---

## 二、后端改动

### 需要改动的文件

| 文件 | 作用 |
|------|------|
| `sql/mall_tiny.sql` | 插入菜单数据到 `ums_menu` 表 |

### 数据库操作

在 `ums_menu` 表插入两条记录：

```sql
-- 一级菜单：药材保障
INSERT INTO ums_menu (parent_id, create_time, title, level, sort, name, icon, hidden)
VALUES (0, NOW(), '药材保障', 0, 0, 'medicine', 'product', 0);

-- 二级菜单：药材字典（使用 LAST_INSERT_ID() 获取上一条插入的 id 作为 parent_id）
INSERT INTO ums_menu (parent_id, create_time, title, level, sort, name, icon, hidden)
VALUES (LAST_INSERT_ID(), NOW(), '药材字典', 1, 0, 'medicineDrug', 'product-list', 0);
```

**注意**：id 使用自增，无需手动指定。

### 关键字段说明

| 字段 | 含义 | 示例值 |
|------|------|--------|
| `parent_id` | 父菜单ID，0表示一级菜单 | 0 或上级ID |
| `level` | 菜单层级，0=一级，1=二级 | 0, 1 |
| `sort` | 排序序号，数字越小越靠前 | 0 |
| `name` | 前端路由名称（必须与前端 route.name 一致，且不能与其他菜单重复） | medicine |
| `icon` | 图标名称（前端 SVG 类名） | product |
| `hidden` | 是否隐藏，0=显示，1=隐藏 | 0 |

### 后端无需写代码

菜单管理使用已有的 `ums` 模块：
- Controller: `UmsMenuController` (已有)
- Service: `UmsMenuService` (已有)
- 只需在数据库插入数据即可

## 三、前端改动

### 需要改动的文件

| 文件 | 作用 |
|------|------|
| `src/router/index.js` | 添加路由配置 |
| `src/views/medicine/drug/index.vue` | 创建对应的页面组件 |

### 步骤 1：在路由中添加菜单

编辑 `src/router/index.js`，在 `asyncRouterMap` 数组中添加：

```javascript
{
  path: '/medicine',
  component: Layout,          // 布局组件（已有）
  redirect: '/medicine/drug',  // 默认跳转
  name: 'medicine',           // 必须与后端 name 字段一致！
  meta: { title: '药材保障', icon: 'product' },
  children: [
    {
      path: 'drug',
      name: 'medicineDrug',   // 二级菜单路由名
      component: () => import('@/views/medicine/drug/index'),
      meta: { title: '药材字典', icon: 'product-list' }
    }
  ]
}
```

### 步骤 2：创建页面组件

创建文件 `src/views/medicine/drug/index.vue`：

```vue
<template>
  <div class="medicine-drug">
    <h1>药材字典</h1>
    <!-- 页面内容 -->
  </div>
</template>

<script>
export default {
  name: 'MedicineDrug'  // 必须与路由 name 一致
}
</script>
```

## 五、关键对应关系

```
后端 ums_menu.name = 'medicine'     ←→  前端 route.name = 'medicine'
后端 ums_menu.name = 'medicineDrug' ←→  前端 route.name = 'medicineDrug'
```

**注意**：
1. 前后端的 `name` 字段必须完全一致，菜单才能正确显示和访问
2. `name` 不能与数据库中其他菜单重复（如已存在的 `pms` 是商品模块）
